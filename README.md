# taigi-class-games

宗龍的台語課（臺中明道中學）各版本教科書課堂遊戲，由 Google Sites 內嵌程式碼搬到 GitHub Pages 統一管理。

- 總目錄：https://cyril-mingdao.github.io/taigi-class-games/
- 一個遊戲一個資料夾，底下依版本分資料夾，每課一個 html：`<遊戲>/<版本代號>/L<課>.html`

| 資料夾 | 遊戲 |
|---|---|
| `hingim/` | 形音義配對 |
| `siann/` | 咱來餾生份字 |
| `suansu/` | 選詞塌空 |
| `tauku/` | 咱來鬥句 |
| `mindmap/` | 心智圖配對比輸贏 |

| 版本代號 | 版本 |
|---|---|
| `CHINPING-B1` | 真平版國中第1冊 |
| `KANGHSUAN-B2` | 康軒版國中第2冊 |
| `YUDA-B1` | 育達版高中全1冊 |
| `CHUANHWA-B3` | 全華版國中第3冊 |
| `common` | 共用（不分版本） |

完整課次連結見 [links.md](links.md)。
